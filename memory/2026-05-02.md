## Railway + Supabase Deployment (FINALLY WORKING!)

- **Problem:** Tasks weren't saving on dashboard refresh
- **Root cause:** Tasks table schema used different column names than our code expected
- **Schema discovered:** content (not title), status (not column), priority (integer), assigned_to and tags columns don't exist
- **Fix:** Rewrote index.js to map:
  - title → content
  - column → status
  - Removed assigned_to and tags (not in schema)
- **Verification:** Created test task directly via Supabase REST API - appeared on dashboard!
- **Status:** GET working, POST needs UUID format for IDs (dashboard sends string IDs)
