# MISSION CONTROL: CORE ENGINEERING PROTOCOL
## Agentic Labs | System Integrity & Troubleshooting Guide

### 1. THE ARCHITECTURAL "TRUTH"
To prevent data loss and system crashes, these principles are absolute:
* **API-First Handoff:** The frontend MUST NOT write directly to Supabase for new tasks. New tasks use temporary timestamp IDs that will crash Postgres. Hand them to `/api/tasks` so the backend can generate a valid UUID.
* **Partial Update Mandate:** Never use a full `.upsert()` if any columns are missing from your local data. Use `.update().eq('id', taskId)` to preserve existing `description`, `tags`, and `assigned_agent` fields.
* **Field Mapping Dictionary:** - UI: `column` <—> DB: `status` (Must be UPPERCASE in DB).
    - UI: `task_name` <—> DB: `content`.
    - UI: `assignedTo` <—> DB: `assigned_agent`.

### 2. TROUBLESHOOTING RUNBOOK
If the system exhibits the following symptoms, execute these fixes:

#### Symptom: White Screen on Load
* **Cause:** The Root Route (`app.get('/')`) is missing in `index.js`.
* **Fix:** Ensure `index.js` uses `fs.readFile` to serve `index.html` at the base URL.

#### Symptom: Tiles Disappear on Refresh
* **Cause 1:** ID Mismatch. The frontend is still using a timestamp ID instead of the UUID generated by the API.
* **Fix 1:** Ensure `pushTruth` in the frontend calls `fetchLatest()` immediately after a successful POST to sync the real IDs.
* **Cause 2:** Client ID Filtering. The API is filtering by a `client_id` that doesn't exist on the records.
* **Fix 2:** Verify all tasks in Supabase have the `client_id` matching the `TEST_ID` in `index.js`.

#### Symptom: Tiles "Pop" Out of Columns
* **Cause:** CSS Flexbox constraints.
* **Fix:** Ensure `.columns-container` has `align-items: flex-start` and columns have `height: auto`.

### 3. SENSITIVE DATA GAURDORAILS
* **Environment:** Always prefer `process.env` for Supabase keys.
* **Safety Net:** If the backend hits a 500 error, it is programmed to auto-generate an "Error Task" in the INBOX. Check the board for these heartbeats.
